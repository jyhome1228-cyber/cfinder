# C-Finder 브랜드·비주얼 시스템 (v1, 2026-11-24)

## 디자인 방향 결정
기존 홈페이지의 카피 중심 장식과 임의 캐릭터 의존도를 낮추고 **신뢰감 있는 교육 진단 서비스 + 직관적인 검사 진입**을 결합한다. 로고는 디자이너 및 운영사의 최종 승인 전 사용되는 **구현안**이며, 공인·연구실 로고를 대체하지 않는다.

### 심볼 선택 및 후보
- **채택: C + 탐색 초점 + 3개 요소** — 열린 C는 탐색을, 중앙 라임 점은 개인의 발견을, 3개 방향 점은 흥미·적성·가치관의 통합을 표현한다.
- 후보 B: 3개 축 나침반 — 지향과 탐색의 의미가 명료하나 앱 아이콘 축소에서 복잡할 수 있다.
- 후보 C: 렌즈 + 점 3개 — 진단·분석의 의미가 명확하지만 일반적인 검색 브랜드와 혼동될 수 있다.

선정 로고는 `assets/brand/cfinder-mark.svg`, `assets/brand/cfinder-wordmark.svg`, 배경 모티프는 `assets/brand/cfinder-motif.svg`에 보관한다. 기존 회사의 공식 등록 상표나 아주대학교 로고로 오인할 표현은 넣지 않는다.

## 타이포그래피와 구성
Pretendard를 서비스 기본 글꼴로 사용한다. 헤드라인은 간결하게, 보조 텍스트는 반드시 의미가 있는 경우에만 노출한다. 최대 콘텐츠 폭은 1344px; 검사 흐름은 좁은 읽기 폭으로 유지한다. 모바일 360/390px 및 태블릿 768px을 기준으로 재배치한다.

## 반복 가능한 시각 문법
- 검사: 5단계 블루 원형 라디오 응답
- 진로: Holland RIASEC 6종 배지/인물 SVG 일러스트 (**삽화이지 연구팀 승인 유형 캐릭터가 아님**)
- 점수: 실제 승인된 샘플 자료에 한해 막대·레이더 차트 활용
- 결과: 진로 유형 → 요인별 상세 → 직업 추천. 실제 진단이 아닌 샘플 여부를 명확히 표시한다.
- 도입: 공식 홍보페이지는 검사 서비스와 별도 운영한다.

## 일러스트·기술 사용 제한
생성 이미지의 임의 통계 백분율, 점수, 대학생 검사 정식화 주장 및 확정되지 않은 검사 프로세스를 UI에 넣지 않는다. C-Finder 화면 체험의 문항은 연구팀의 정식 문항이 아니며, 점수/유형 자동 산출은 하지 않는다.

## 사용자 확정 SVG 반영 (2026-11-24)

위 문서의 C+탐색 초점 형태는 **이전 임시 시안**이며 현재 공식 화면 로고로 사용하지 않습니다. 사용자가 Illustrator에서 제공한 파란색 원본(색상 **#214FF4**, 뷰박스 426.97×107.05)을 다음과 같이 반영했습니다.

- `assets/brand/cfinder-official-logo.svg` — 원본 로고의 벡터 path와 polygon을 그대로 유지한 메인/홍보 공통 로고
- `assets/brand/cfinder-official-mark.svg` — 동일 원본의 캐릭터 형태를 분리한 브라우저 파비콘
- `assets/brand/cfinder-loader.svg` — 제공된 로딩 SVG의 흰 캐릭터와 7개 점에 순차 소거와 수평 이동 모션을 적용
- `assets/brand-loading.css` — 최초 방문 로딩 전체 화면 및 건너뛰기 레이아웃

비주얼 파일 색상은 원본 그대로 두며, 서비스 버튼용 블루(#1957EF)는 기존 디자인 토큰을 유지합니다. 사용자의 최종 원본 파일이 우선하며 향후 브랜딩 시안과 혼용하지 않습니다.
