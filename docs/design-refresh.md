# C-Finder 디자인 개선 기록

작성일: 2026-11-23

## 목적과 배포 대상

기존 메인의 큰 벤다이어그램과 단조로운 박스 구성을 개선합니다. 진단검사를 중심에 두고, 학생이 학교급을 선택해 체험을 시작하고 결과지 구성을 이해하도록 화면을 정리했습니다.

배포 대상은 기존 저장소의 `main`과 **https://jyhome1228-cyber.github.io/cfinder/** 입니다. 별도 사이트로 이전하지 않습니다.

## 변경 내용

- **메인:** 흥미는 펼쳐지는 꽃, 적성은 쌓이는 블록, 가치관은 중심이 있는 마름모로 표현했습니다. 이 세 가지 그래픽을 메인, 영역 소개, 결과지에 반복해 사용합니다.
- **검사 진입:** 중학생용·고등학생용 버튼을 첫 화면에 두고 기존 이어하기·완료 상태 표시를 유지합니다. 체험 범위는 버튼 아래에 안내합니다.
- **화면 구성:** 영역 소개는 탭과 구분선 중심으로, 결과지 미리보기는 한 장의 문서 형태로, 기관 소개는 브랜드 설정 예시와 운영 준비 항목으로 정리했습니다.
- **서체:** Pretendard v1.3.9 가변 폰트를 실제 파일로 포함하고 선행 로드합니다. 서체 파일은 원본 그대로이며 SIL OFL 1.1을 함께 제공합니다.
- **글씨:** 메인 제목은 기본 16px 환경에서 데스크톱 30px, 모바일 24~26px입니다. 본문은 15~16px, 보조 글씨는 최소 14px입니다.
- **검사 화면:** 데스크톱의 5점 응답 척도를 한 줄로 정리하고 모바일에서는 세로로 배치합니다. 안내·검토·완료·결과지 화면의 여백과 구분선을 통일했습니다.
- **배포 자산:** 상대 경로, 해시 라우트와 기관 설정 구조를 유지합니다. 로컬 서버에 WOFF2 MIME 형식을 추가하고 HTML에 기존 GitHub Pages 정규 주소를 지정했습니다.

## 확인 결과

| 구분 | 이번에 확인한 내용 |
| --- | --- |
| 코드 | `npm run check`: JavaScript 14개 파일, 상대 경로 모듈·진입 자산 연결 통과 |
| 기존 테스트 | `npm test`: 25개 통과, `git diff --check` 통과 |
| 메인 | 320·390·768·1024·1440px 브라우저 프레임에서 가로 넘침 없음. 세 그래픽의 문구가 가려지지 않음 |
| 서체·글씨 | 실제 Pretendard 로드 확인. 좁은 화면의 메인 문구 최소 14px 확인 |
| 접근 조작 | 영역 소개 탭의 키보드 이동, 문항 라디오의 방향키 선택 확인 |
| 중학생용 | 안내→3문항 응답→검토→첫 응답 수정→완료 흐름 확인 |
| 고등학생용 | 390px 프레임에서 3문항 응답→검토→완료 흐름 확인 |
| 다시 시작 | 320px 프레임의 대화상자·48px 버튼 확인, 취소 시 완료 상태 유지 확인 |
| 하위 화면 | 데스크톱 결과지·기관 소개 검토, 320px 프레임 결과지·기관 소개에 가로 넘침 없음 |
| 기관 예시 | 320px 프레임에서 기관명·안내 문구·테마 전환 및 가로 넘침 없음 확인 |

프레임 너비는 브라우저 내부 검수 도구로 지정했습니다. 스크롤바가 있는 환경에서는 실제 내용 영역이 지정값보다 15px 작았습니다. 실제 휴대전화·Safari 등 다른 브라우저 검증은 포함하지 않습니다. 공개 배포 완료 여부는 GitHub Pages 작업과 실제 주소에서 확인합니다.

## 현재 제품 범위

현재 검사는 학교급별 **가상 3문항 체험**입니다. 공식 문항, 채점, 개인 진로 유형·추천, 서버 응답 저장, 기관 관리자 화면은 이번 디자인 변경에 포함되지 않습니다. 결과지 화면은 개인 결과가 없는 구성 예시입니다.

후속 작업은 [검사 데이터·결과 계약](assessment-contract.md)에 따라 승인된 문항과 산식, 해석·추천 자료, 기대 결과를 연결하고 검증하는 것입니다.
