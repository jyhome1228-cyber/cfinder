# C-Finder 9개 예시 문항 QA (2026-11-24)

## 범위와 판정
검수 대상은 공개 GitHub 저장소 `assets/data/assessments.js`에 들어 있는 **중학생 3개·고등학생 3개·대학생 3개**의 화면 체험 문항 9개다. 이는 연구팀의 정식 문항 원고가 아니며, 첨부된 고등학생용 3쪽 결과지에는 문항 원문·문항-요인 대응표·문항별 역채점·채점식이 포함돼 있지 않다.

**결론:** 9개 예시 문항은 모두 어휘·행동 명료성 관점에서 교정했고 화면 체험에 사용할 수 있는 수준으로 정리했다. 그러나 진로 흥미·적성·가치관을 각각 한 문항으로만 묻는 현재 구조는 신뢰도·타당도·세부 점수·RIASEC 진로 유형을 추정할 수 없다. **정식 진단으로 사용 불가.**

## 공통 원칙
- 한 문항에 한 가지 비교적 구체적인 행동·평가 기준만 제시한다.
- 중학생은 일상 활동과 이해 가능한 어휘, 고등학생은 전공·직업 탐색, 대학생은 직무·프로젝트 경험을 대상으로 한다.
- "탐색할 필요성"이나 "내가 중요하게 생각하는 기준이 무엇인지 고민한다"처럼 높은 점수를 주기 쉬운 일반적 바람직함·모호한 자기성찰 표현은 줄인다.
- 진단 결과를 산출하지 않으므로 **설문형 5점 척도는 시연용**이며 심리측정 동등성·요인 타당도는 입증되지 않았다.
- 응답자 안내는 합격/불합격이나 적성 진단을 암시하지 않게 유지한다.

## 사용자 경험 QA
1. 세 학교급 모두 문항 3개, 선택지 5개, 흥미 → 적성 → 가치관 순서가 유지돼야 한다.
2. 각 문항은 1~5 정수만 허용하고 응답 없이 다음 문항 진행을 막아야 한다.
3. 선택지 접근성: 라디오 입력, 키보드 초점, 명확한 선택 표시, 스크린리더 문항 문맥.
4. 응답 수정·검토·완료·다시 시작하기와 학교급별 독립 저장을 회귀 테스트한다.
5. 문항이 수정되면 버전을 바꿔 이전 버전의 응답을 현재 문항에 이어 붙이지 않는다.
6. 3문항 체험 완료 시 개인 점수, Holland 유형, 추천 직업을 계산하지 않는다. 샘플 결과지는 따로 표기한다.

## 정식화 전에 필요한 문서 및 연구팀 승인
- 중등·고등 정식 전체 문항과 옵션 원고, 문항 순서, 하위요인 매핑, 문항별 난이도·표준화 근거
- 역문항 처리, 동점 처리, 점수 합산/변환, RIASEC 유형 산출과 추천 직업 연결 규칙
- 검사 대상별 규준과 신뢰도·타당도 자료, 결과 해석 문구 및 개인정보 처리계획
- 대학생용 적용 범위, 별도 문항 개발 및 표본 검증 여부

**주의:** 이 문서는 사용자 제공 PDF 결과지와 현재 코드의 예시 문항만 비교한 편집·UX QA 기록이다. 심리측정 전문가의 문항 승인이나 통계적 타당도 검증을 대신하지 않는다.
